# git-erste-schritte

In diesem Projekt ging es darum, erste Brührungspunkte mit GitHub und Visual Studio Code zu haben. Dabei habe ich gelernt, wie man eine Repository, eine Branch und eine READ.ME Datei anlegt, in einer READ.ME Datei einen Text mithilfe von # als Überschrift kennzeichnet und alles speichert. 

Drei wichtige zentrale Begriffe waren dabei:
- Repositoriy, also quais der Überordner eines Projektes mit allen Informationen
- Branch, also quasi Unterordner in einem Projekt mit einzelnen Arbeitsschritten
- Commit, also das Abspeichern des aktuellen Arbeitsstandes
